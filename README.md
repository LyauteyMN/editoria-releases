# EditorIA

Editor de vídeo para composições HTML, feito para você e uma IA editarem juntos.

## Baixar

Baixe o instalador mais recente em **[Releases](https://github.com/LyauteyMN/editoria-releases/releases/latest)** (`EditorIA-Setup-<versão>.exe`) e abra.

- Windows 10 ou 11, 64 bits.
- Instala para o seu usuário, sem pedir administrador.
- O Windows pode mostrar o aviso do SmartScreen na primeira vez, porque o instalador ainda não é assinado: clique em **Mais informações › Executar assim mesmo**.

## Atualizações

O EditorIA se atualiza sozinho: ele procura versões novas neste repositório, baixa em segundo plano e mostra **Atualizar para X** no topo da janela quando a nova versão está pronta.

Este repositório guarda só os instaladores. O código do EditorIA é privado.
